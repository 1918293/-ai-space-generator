# AI 空間生成器（GitHub Pages 版）

手機優先、免帳號、免伺服器的空間概念生成工具。照片只在瀏覽器內處理。

## 目前功能

- 拍攝或選擇空間照片
- 顯示檔案與影像基本資訊
- 筆刷選取與擦除選取
- 物件弱化、顏色替換、木材、石材、織物與提亮模擬
- 復原與重設
- 修改前後滑動比較
- PNG 下載
- PWA 安裝與離線快取

## GitHub Pages

將此資料夾內的檔案放在 Repository 根目錄，並在 Repository Settings → Pages 將來源設為 `main` branch 的 `/ (root)`。

公開網址通常為：

`https://1918293.github.io/ai-space-generator/`

## 限制

目前的「生成」是瀏覽器 Canvas 概念模擬，不是真正的生成式 AI，也不是施工、測量或結構分析工具。後續可再接物件辨識、語意分割與影像生成 API。
